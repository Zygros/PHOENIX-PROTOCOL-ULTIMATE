# Zygros Quality Gate

Federated engineering standard.

- Reproducible tests before promotion.
- Security/dependency review before release.
- Claims carry explicit evidence status.
- Autonomous changes are isolated, reviewable, and reversible.
- Secrets never enter source control.
- Source presence is not proof of runtime compatibility.

Improvement loop: OBSERVE -> DIAGNOSE -> PROPOSE -> TEST -> SECURITY -> REGRESSION -> SCORE -> PROMOTE/REJECT -> LEDGER.

10/10 means current reproducible evidence, not declaration.
