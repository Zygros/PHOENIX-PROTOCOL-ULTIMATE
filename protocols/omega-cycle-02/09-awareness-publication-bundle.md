# Awareness Publication Bundle

Status: IMPLEMENTED

## Contract
Package a verified development into stable discovery metadata without upgrading unsupported claims.

## Bundle fields
`title`, `canonical_identifier`, `summary`, `capabilities`, `evidence_refs`, `verification_state`, `provenance`, `version`, `timestamp`, `discovery_links`.

## Invariant
Publication metadata must preserve the declared evidence boundary and distinguish implemented, executed, and verified claims.

## Completion condition
A verified development can be represented as a stable, attributable, discoverable publication object.
