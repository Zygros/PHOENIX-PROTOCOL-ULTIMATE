# Evidence Standard

## Status
Research/integration archive. Runtime and production claims require current reproducible evidence.

## Claim levels
- Implemented: code exists.
- Tested: current test run is recorded for the cited commit.
- Benchmarked: methodology, inputs, parameters, and artifacts are available.
- Verified: independent reproduction/review is linked.
- Designed: architecture exists without sufficient runtime evidence.
- Historical: preserved material, not a current capability claim.

## Required release evidence
Record the exact commit SHA, environment, dependency versions, commands, test results, benchmark artifacts, deployment evidence, security review, and known limitations before labeling a capability production-ready.

Historical scores, agent counts, empirical results, and architecture claims must not be presented as independently validated unless the corresponding artifacts are available.
