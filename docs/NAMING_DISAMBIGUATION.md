# Phoenix Naming Disambiguation

Two systems share the name Phoenix.

1. **Phoenix Protocol (Zygros)** — https://github.com/Zygros/PHOENIX-PROTOCOL-ULTIMATE — a deterministic, hash-chained verification substrate. AGI-as-architecture thesis. Demonstration Zero: one reproducible round-trip, sub-millisecond, SHA-256 sealed.

2. **Phoenix (arXiv 2606.20243)** — a multi-agent LLM system for resolving GitHub issues, benchmarked at 75% oracle resolution on a SWE-bench Lite slice by researchers at a Kenyan institution (June 2026).

They solve different problems. This repo is the verification engine; that paper is a code-resolution agent. Cross-reference is encouraged; confusion is not.

Always add. Never take.
