# Collective Intelligence Score — Independent Reproduction Plan

## Reported Values

- 0.285 from 101 agents (PHOENIX-PROTOCOL-ULTIMATE)
- 0.783 to 0.809 in Claude-shared 32-to-128-node runs

## Problem

No independent party has re-run these. The numbers are self-reported.

## Method

1. Fix a random seed.
2. Run the 101-agent configuration.
3. Run the 32-node and 128-node Claude-shared configurations.
4. Record mean, variance, and per-run distribution.
5. Publish raw logs alongside aggregates.

## Acceptance

- Seed published.
- Raw logs published.
- Variance reported, not just means.
- Any divergence from reported values documented honestly.

Always add. Never take.
